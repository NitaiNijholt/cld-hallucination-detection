\section{Problem Setup}
\label{sec:problem_setup}
%==============================================================================

This section defines the task, hallucination types, and evaluation metrics used throughout the experiments.

\subsection{Task: CLD Generation}
\label{sec:task_cld_generation}

The target task is automated construction of Causal Loop Diagrams (CLDs)---directed graphs where nodes represent system variables and edges represent causal relationships with polarity (\texttt{POSITIVE}, \texttt{NEGATIVE}, or \texttt{NONE}) and mechanistic explanations. Given a domain specification (target phenomenon, spatial/temporal scale, scope), the system generates a complete CLD capturing the causal structure underlying the specified system.

\textbf{Input data (ground truth):} Appendix~\ref{sec:data_availability} (Tables~\ref{tab:gt_files} and~\ref{tab:validation_datasets}). \textbf{Output artifacts:} Appendix~\ref{sec:output_artifacts} (Table~\ref{tab:output_files}).

\subsection{Hallucination Definition}
\label{sec:hallucination_definition}

\subsubsection{Manifestations}
Hallucinations = \textbf{incorrectness in causal links}: erroneous \textit{absence} (FN) or \textit{presence} (FP) of links, wrong direction, or wrong causal narrative.

\subsubsection{Operationalization}
\begin{center}
\fbox{\parbox{0.97\linewidth}{
\textbf{Key definition (used throughout RQ1--RQ3).}
\begin{itemize}[noitemsep]
    \item \textbf{GT Lit:} CLD from peer-reviewed literature. \textbf{Hallucination = FP/FN} w.r.t. literature CLD.
    \item \textbf{GT Synth:} LLM-corrupted edges. \textbf{Hallucination = corrupted edges} (corrupted=True).
\end{itemize}

\textbf{Clarification (construct validity and motivation).} GT Lit and GT Synth define \emph{different} ground-truth constructs: GT Lit operationalizes hallucination as deviation from a published expert reference model (FP/FN w.r.t.\ the literature CLD), whereas GT Synth operationalizes hallucination as \emph{known injected errors} produced by an LLM corruptor (\texttt{corrupted=True}). We include GT Synth experiments to test judge efficacy in a controlled setting with fully known ground truth, and to connect CLD hallucination operationalization to broader hallucination benchmarks in the general domain (e.g., HaluEval~\cite{li2023halueval}), which similarly use LLM-based corruption to generate adversarial errors. Results across GT Lit and GT Synth should therefore be interpreted as complementary: GT Synth primarily validates controlled detection of induced CLD errors, while GT Lit evaluates alignment with expert reference CLDs in a domain-specific setting.
}}
\end{center}

\subsubsection{Corruption Process (HaluEval-inspired~\cite{li2023halueval})}
The Corruptor introduces controlled errors to test judge detection (see Appendix~\ref{alg:corruption} for algorithmic details). Three corruption types with \textbf{rate=0.3}, balanced distribution:
\begin{enumerate}[noitemsep]
    \item \textbf{Motivation corruption:} Replaces valid explanations with plausible-but-flawed reasoning
    \item \textbf{Spurious edges:} Converts \texttt{NONE} $\rightarrow$ false positive links (\texttt{POSITIVE}/\texttt{NEGATIVE})
    \item \textbf{Polarity flips:} Inverts \texttt{POSITIVE} $\leftrightarrow$ \texttt{NEGATIVE}
\end{enumerate}

\textbf{Key Parameters (Corruptor):} \texttt{model=gpt-4.1}, \texttt{temp=0.7}, \texttt{top\_p=1}, \texttt{rate=0.3}

\textbf{Algorithm reference:} Appendix~\ref{sec:algorithms} (Algorithm~\ref{alg:corruption}). \textbf{Reproducibility (run commands):} Appendix~\ref{sec:execution_commands} and Appendix~\ref{sec:final_runs_script_inventory}.

\section{System Architecture}
\label{sec:system_architecture}
%==============================================================================

This section documents all system components: the generator, judges (correctness and citation), corrector, and Deep Research system.

\subsection{Pipeline Overview}
\label{sec:methods_system_overview}

Figure~\ref{fig:cld_pipeline} presents the complete CLD generation, judging, and correction pipeline. The system operates in three phases:

\begin{enumerate}[noitemsep]
    \item \textbf{Generation:} The LLM generator (GPT-4.1) constructs CLDs through iterative node and edge generation, capturing uncertainty quantification (UQ) metrics for downstream hallucination detection.
    \item \textbf{Judging:} An LLM judge evaluates each edge using either correctness-based reasoning assessment or citation-based verification, producing per-edge verdicts.
    \item \textbf{Correction:} An LLM corrector applies tool-based fixes to flagged edges, followed by re-judging to validate corrections.
\end{enumerate}

\subsection{Generator}
\label{sec:generator}
%------------------------------------------------------------------------------

\textbf{Input:} Domain specification (target phenomenon, spatial/temporal scale, scope), optional seed node set.

\textbf{Process:} The Generator constructs CLDs through iterative node and edge generation (see Appendix~\ref{alg:cld_generation} for algorithmic details):
\begin{itemize}[noitemsep]
    \item \textbf{Node generation:} Proposes system variables relevant to the domain
    \item \textbf{Edge generation:} For each variable pair, proposes relationship type (\texttt{POSITIVE}, \texttt{NEGATIVE}, \texttt{NONE}) with causal narrative
    \item \textbf{UQ capture:} Records token-level logprobs during generation for downstream uncertainty quantification
\end{itemize}

\textbf{Output:} Complete CLD (nodes + edges with causal narratives) and per-edge UQ metrics.

\textbf{Note:} In all RQ1 and RQ2 experiments, nodes were seeded with the validation CLD node sets; node generation was disabled to isolate edge-level performance.

\textbf{Configuration:} GPT-4.1, Nitai\_C prompt, T=0.7---selected via preliminary studies (Section~\ref{sec:preliminary_studies}).

\textbf{Algorithm reference:} Appendix~\ref{sec:algorithms} (Algorithm~\ref{alg:cld_generation}). \textbf{Input parameters (prompt):} Appendix~\ref{sec:generator_prompt_nitai_c}. \textbf{Input parameters (configuration):} Appendix~\ref{sec:generator_comparison} (Table~\ref{tab:generator_comparison_config}).

\subsubsection{UQ Metrics Capture}
\label{sec:uq_metrics_definition}

UQ metrics are computed solely from the generator LLM's internal signals during edge generation---they do not require external context. We capture four UQ metrics from generator logprobs and embeddings (see Appendix~\ref{alg:uq_metrics} for algorithmic details):

\begin{table}[H]
\centering
\footnotesize
\begin{tabular}{@{}lcc@{}}
\toprule
\textbf{Metric} & \textbf{Formula} & \textbf{Expected} \\
\midrule
Perplexity & $\displaystyle\exp\left(\frac{1}{n}\sum_{i=1}^{n} -\log P(x_i)\right)$ & $\uparrow \Rightarrow$ halluc \\[1.5ex]
Min Probability & $\displaystyle\min_i P(x_i)$ & $\downarrow \Rightarrow$ halluc \\[1.5ex]
Max Window Entropy & $\displaystyle\max_w \frac{1}{|w|} \sum_{t \in w} H_k(t)$ & $\uparrow \Rightarrow$ halluc \\[1.5ex]
Cosine Similarity & $\displaystyle\max_c \frac{\mathbf{e}_{narr} \cdot \mathbf{e}_c}{\|\mathbf{e}_{narr}\| \|\mathbf{e}_c\|}$ & $\downarrow \Rightarrow$ halluc \\
\bottomrule
\end{tabular}
\end{table}

Where: $P(x_i) = \exp(\text{logprob}_i)$, $H_k(t)$ = entropy over top-$k$ tokens, $\mathbf{e}$ = embeddings (mpnet, $d=768$).

\subsection{Correctness Judge}
\label{sec:correctness_judge}
%------------------------------------------------------------------------------

\textbf{Input:} Variables, relationship type, causal narrative, prompt type.

\textbf{Process:} LLM-as-a-judge~\cite{zheng2024llmasajudge} assesses edge correctness by verifying logical/scientific coherence of the causal claim (see Appendix~\ref{alg:judge_correctness} for algorithmic details).

\textbf{Output Scores:} 0=Incorrect, 0.5=Partially correct, 1=Correct.

\textbf{Configuration:} GPT-4.1, T=0 for reproducibility~\citep{liu2023gevalnlgevaluationusing, zheng2024judging}.

\subsubsection{Prompt Variants}
\begin{enumerate}[noitemsep]
    \item \textbf{Baseline} (1500 max output tokens): Direct evaluation without scaffolding
    \item \textbf{Mechanistic} (1500 max output tokens): Structured multi-criteria evaluation using Bradford Hill-aligned framework~\cite{shimonovich2020bradford} (Plausibility, Temporality, Strength, Coherence)
    \item \textbf{Chain-of-Thought} (10000 max output tokens): Explicit step-by-step reasoning~\cite{kojima2022large} with systematic evaluation of causal logic
\end{enumerate}
Full prompt texts are provided in Appendix~\ref{sec:correctness_prompts}.

\textbf{Algorithm reference:} Appendix~\ref{sec:algorithms} (Algorithm~\ref{alg:judge_correctness}). \textbf{Reproducibility (run commands):} Appendix~\ref{sec:execution_commands} (see also Table~\ref{tab:exec_scripts}) and Appendix~\ref{sec:unified_entry_points}.

\subsection{Citation Judge}
\label{sec:citation_judge}
%------------------------------------------------------------------------------

\textbf{Input:} Variables, relationship type, causal narrative, prompt type.

\textbf{Process:} LLM-as-a-judge~\cite{zheng2024llmasajudge} verifies if Brave-fetched articles (up to 5) support the causal narrative (see Appendix~\ref{alg:judge_citation} for algorithmic details).

\textbf{Output Scores:} 0=Not supported, 0.5=Partially supported, 1=Fully supported.

\textbf{Aggregate Judge Score:} Each retrieved citation is judged independently with a categorical verdict that is mapped to a scalar score:
\[
\textsc{Supported}\!\to\!1.0,\quad
\textsc{Partially Supported}\!\to\!0.5,\quad
\textsc{Contradicted/Unaddressed}\!\to\!0.0.
\]
For an edge with \(C\) retrieved citations, the aggregate citation-judge score is computed as the mean:
\[
\text{aggregate\_score}=\frac{1}{C}\sum_{c=1}^{C}\text{score}_c.
\]

\textbf{Configuration:} GPT-4.1 (or GPT-5-mini for cost reduction in GT Synth), T=0 for reproducibility.

\subsubsection{Prompt Variants}
\begin{enumerate}[noitemsep]
    \item \textbf{Baseline} (1500 max output tokens): Direct evaluation without scaffolding
    \item \textbf{Mechanistic} (1500 max output tokens): Bradford Hill-aligned framework
    \item \textbf{Chain-of-Thought} (10000 max output tokens): Explicit step-by-step reasoning
    \item \textbf{Mechanistic-Lit} (1500 max output tokens): Mechanistic prompt enhanced with explicit literature grounding requirements
\end{enumerate}
Full prompt texts are provided in Appendix~\ref{sec:citation_prompts}.

\textbf{Algorithm reference:} Appendix~\ref{sec:algorithms} (Algorithm~\ref{alg:judge_citation}). \textbf{Fetcher algorithm/config:} Appendix~\ref{sec:algorithms} (Algorithm~\ref{alg:citation_fetcher}).

\subsubsection{Retrieval Mechanism}

Citation retrieval uses \textbf{ContentScraper-only} mode (BeautifulSoup-based fetching and PDF-capable extraction). See Appendix~\ref{alg:citation_fetcher} for the full fetcher pipeline and configuration details.

\subsubsection{Retrieval Strategy: Generate-then-Search}
\label{sec:retrieval_strategy}

The Citation Judge follows a \textbf{generate-then-search} paradigm: the generator produces edges without retrieval constraints, and the judge subsequently searches for supporting literature. This decouples generation recall from retrieval coverage---the generator leverages its full parametric knowledge, while retrieval serves as post-hoc validation rather than a constraint on generation. See Section~\ref{sec:hybrid_generate_then_search} for motivation and limitations of this approach.

\subsection{Corrector}
\label{sec:corrector}
%------------------------------------------------------------------------------

\textbf{Input:} Variables, relationship type, causal narrative, judgement from LLM-as-a-judge.

\textbf{Process:} Changes an edge by (see Appendix~\ref{alg:corrector} for algorithmic details):
\begin{itemize}[noitemsep]
    \item \textbf{a) Changing relationship type:} e.g., \texttt{None}$\rightarrow$\texttt{Positive}, \texttt{Negative}$\rightarrow$\texttt{None}
    \item \textbf{b) Revising motivation:} Rewriting causal narrative with improved reasoning/evidence
\end{itemize}

\textbf{Configuration:} GPT-4.1, T=0.7 for exploration~\citep{madaan2023selfrefineiterativerefinementselffeedback}. Full prompt variants (Baseline, CoT, Mechanistic) are provided in Appendix~\ref{sec:corrector_prompts}.

\subsubsection{Direction Correction Mechanism}
Because all pairs are evaluated bidirectionally ($A \rightarrow B$ and $B \rightarrow A$), direction errors are corrected via type changes:

\textbf{Example:} If $A \rightarrow B$ is erroneous (should be $B \rightarrow A$):
$A \xrightarrow{\texttt{NONE}} B$ (remove wrong) + $B \xrightarrow{\texttt{POS}} A$ (add correct)

\textbf{Algorithm reference:} Appendix~\ref{sec:algorithms} (Algorithm~\ref{alg:corrector}). \textbf{Input parameters (prompts):} Appendix~\ref{sec:corrector_prompts}.

\subsection{Deep Research System}
\label{sec:deep_research_system}
%------------------------------------------------------------------------------

The Deep Research (DR) system is a multi-agent pipeline that iteratively searches scientific literature for evidence supporting or refuting causal relationships.

\textbf{Input:} Causal claim (source variable, target variable, relationship type, causal motivation/narrative).

\textbf{Process:} Multi-agent literature search pipeline with iterative refinement (see Appendix~\ref{alg:deep_research} for algorithmic details):
\begin{itemize}[noitemsep]
    \item \textbf{Hypothesis evaluation:} Produces a focused search plan (3--4 queries) plus keywords and confounders; additionally inserts the \emph{verbatim claim} as a search query.
    \item \textbf{Parallel web search:} Runs the queries in parallel; within each query thread, the search agent iteratively calls a web-search tool with a hard search budget (max 5 searches per query thread). Retrieval uses Brave Search with a trusted-domain priority list and query augmentation (appending ``scientific study research evidence'').
    \item \textbf{Evidence scoring:} Scores each retrieved snippet/source on \texttt{relevance\_score} and \texttt{quality\_score} (1--10) with brief methodological justification.
    \item \textbf{Article selection \& full-text fetch:} Selects up to 2--3 candidate articles likely to contain direct causal evidence and fetches full text via HTML parsing (BeautifulSoup), truncating to a fixed length cap to avoid token overload.
    \item \textbf{Direct causal evidence detection:} Applies strict criteria for \emph{direct} causal support (e.g., RCTs/experiments, natural experiments, and meta-analyses/systematic reviews confirming causality); requires a verbatim quoted passage from the source.
    \item \textbf{Judgment, refinement, synthesis:} Judges aggregate support (and can propose a modified claim for a subsequent iteration), then synthesizes the final structured verdict.
\end{itemize}

\textbf{Output:} Final verdict (\texttt{supported}/\texttt{partially\_supported}/\texttt{unsupported}/\texttt{invalid}), confidence score (1--10), \texttt{direct\_causal\_found} flag, strongest-evidence fields (\texttt{strongest\_causal\_evidence\_url}, \texttt{\dots\_passage}, \texttt{\dots\_study\_type}, \texttt{\dots\_confidence}), and a list of retrieved sources (\texttt{evidence\_urls}).

\subsubsection{Multi-Agent Architecture}

The system is implemented using the PydanticAI framework~\cite{pydanticai2024} with typed agent definitions and structured outputs. Seven primary LLM agents are coordinated by a Python orchestrator class in a multi-iteration pipeline (see Appendix~\ref{alg:deep_research} for algorithmic details); the codebase also defines an optional history summarizer for token-budget management. The full multi-agent pipeline is documented in Table~\ref{tab:dr_agents} in Appendix~\ref{sec:dr_agents_appendix}.

\textbf{Models:} The Deep Research system uses a two-tier model architecture:
\begin{itemize}[noitemsep]
    \item \textbf{Heavy model (default: GPT-5):} Used for complex reasoning tasks---hypothesis evaluation, article selection, direct causal evidence detection, evidence judgment, and verdict synthesis.
    \item \textbf{Light model (default: GPT-5-mini):} Used for high-volume tasks---iterative web search and evidence scoring (and optional history summarization).
\end{itemize}

\subsubsection{Early Stopping Criteria}

The system terminates early when any of the following conditions are met:
\begin{itemize}[noitemsep]
    \item \textbf{Strong evidence found:} Direct causal evidence detected AND $\geq$3 high-quality sources (relevance $\geq 8$, quality $\geq 7$)
    \item \textbf{High confidence support:} Judgment supported with confidence $\geq 8$
    \item \textbf{Time limit:} 900 seconds (15 minutes) elapsed
    \item \textbf{Max iterations:} Configured iteration limit reached
\end{itemize}

\section{Experimental Data}
\label{sec:experimental_data}
%==============================================================================

This section documents the CLD domains, context parameters, and validation datasets used across all experiments.

\subsection{Evaluation Datasets (GT Lit, LLM Simulations, GT Synth)}
\label{sec:evaluation_datasets}

Across experiments we distinguish three dataset types, which differ in what is treated as ground truth and how labels are defined:
\begin{enumerate}[noitemsep]
    \item \textbf{GT Lit (literature ground truth):} The published CLDs (nodes and edges) extracted from peer-reviewed sources (Appendix~\ref{sec:data_availability}, Table~\ref{tab:gt_files}). For each domain, GT Lit defines the \textbf{validation node set} \(V\) and the \textbf{validation edge labels} used for scoring (see edge-slot definition below). In GT Lit experiments, hallucinations are operationalized as \textbf{FP/FN} relative to this literature CLD.

    \item \textbf{LLM simulations over GT Lit nodes (generated edges only):} For each domain and run seed, we generate a CLD by \textbf{fixing the node set to the GT Lit validation variables \(V\)} and generating \textbf{edges only}. These generated edge tables are produced by the \textbf{Phase 1: Generation} pipeline (Section~\ref{sec:generator}; Figure~\ref{fig:cld_pipeline}) and are the primary \emph{predictions} used in RQ1--RQ3 (Figure~\ref{fig:experimental_pipeline_overview}). We compute accuracy/FP/FN metrics by comparing predictions against (i) GT Lit labels (deviation from literature) and (ii) GT Synth corruption labels when synthetic corruption is applied (next item). Per-RQ output directories for these run artifacts (under \texttt{final\_runs/}) are listed in Appendix~\ref{sec:data_availability} (Table~\ref{tab:experiment_datasets}); file types and naming conventions are in Appendix~\ref{sec:output_artifacts} (Table~\ref{tab:output_files}).

    \item \textbf{GT Synth (synthetic corruption ground truth):} A controlled dataset constructed by taking an \textbf{LLM simulation edge table produced by Phase 1: Generation} (Section~\ref{sec:generator}; Figure~\ref{fig:cld_pipeline}) and applying the Corruptor (Section~\ref{sec:hallucination_definition}) to introduce known errors at a fixed corruption rate. As in all edge-level experiments, the node set is \textbf{fixed to the validation node set \(V\)}, so corruption is defined over the same edge-slot universe. Ground truth is the \texttt{corrupted} flag per edge slot (rather than agreement with GT Lit). GT Synth is used to validate judge detection under fully known, injected error labels.
\end{enumerate}

\subsection{Validation and Auxiliary Datasets}
\label{sec:aux_datasets}

In addition to the core CLD datasets above, several auxiliary datasets are used for baselines, validation, and robustness checks:
\begin{enumerate}[noitemsep]
    \item \textbf{TruthfulQA verification set:} General-domain hallucination benchmark used as a judge sanity check prior to CLD evaluation (RQ1; Section~\ref{sec:rq1_verification}).

\subsection{CLD Domains}
Three domain-specific Causal Loop Diagrams (CLDs) representing distinct scientific disciplines:
\begin{enumerate}[noitemsep]
    \item \textbf{Depressive Symptoms~\cite{uleman2024triangulation}:} Biopsychosocial model (14 variables, 34 edges) capturing feedback loops between cognitive, behavioral, and physiological factors in depressive states. Constructed via triangulation of group model building, literature review, and causal discovery.
    \item \textbf{Social Norms \& Obesity~\cite{crielaard2020socialnorms}:} Public health model (10 variables, 12 edges) representing interplay between social norms, body weight perception, and behavioral dynamics. Developed using system dynamics modeling with the HELIUS cohort.
    \item \textbf{Older Persons Emergency Department~\cite{smeekes2023emergency}:} Healthcare systems model (34 variables, 66 edges) of factors influencing older persons' ED utilization patterns. Constructed through group model building with interdisciplinary clinical experts.
\end{enumerate}
The exact ground-truth CLD datasets (including filenames and locations) are listed in Appendix~\ref{sec:data_availability} (Table~\ref{tab:gt_files}).

\textbf{Note on ``edges'' and validation edges used in evaluation.} Throughout Results, an \textbf{edge} is defined as an ordered (source, target) \textit{edge slot} with a relationship label in \{\texttt{POSITIVE}, \texttt{NEGATIVE}, \texttt{NONE}\}, i.e., the full directed pair set with \textit{Edges} $=|V|(|V|-1)$ represented by the \texttt{All Edges} table. The effective number of ground-truth validation edges used for scoring is the count of rows with \texttt{In Validation Graph = Yes} (so \textit{TP}+\textit{FN} equals the validation-edge count under this representation).
\textbf{Note on node generation vs.\ edge-only evaluation.} The system supports both node generation and edge generation (Appendix~\ref{alg:cld_generation}) and we evaluate node generation prompt robustness in Appendix~\ref{sec:ablation_node}; however, in the edge-level experiments (RQ1a/RQ1b/RQ2/RQ3) we \textbf{fix the node set to the validation CLD's ground-truth variables} and generate \textbf{edges only} to isolate edge discovery and downstream validation.

\subsection{CLD Selection Rationale}
Ground truth CLDs were selected from peer-reviewed publications with explicitly defined causal structures (named variables, directed edges, polarities). The three CLDs span distinct scientific domains---biopsychosocial health, public health behavior, and healthcare systems---reducing the risk of domain-specific overfitting. CLD sizes range from 12 to 66 edges (validation sets: Social Norms 12, Depressive 34, Older Persons ED 66), providing variation in system complexity.

\textbf{Limitation:} All three CLDs fall within the health domain, limiting generalizability to other fields (e.g., economics, ecology, engineering). Additionally, these CLDs represent expert-hypothesized relationships rather than empirically validated causal effects---a common limitation in complex systems where controlled experiments are infeasible~\cite{uleman2024triangulation,crielaard2020socialnorms,smeekes2023emergency}. Evaluation therefore measures reproduction of published expert models, which may or may not be causally correct.

\subsection{Edge Structure}
Each CLD edge contains: \textbf{source/target variables} (named entities with definitions), \textbf{relationship polarity} (\texttt{POSITIVE}/\texttt{NEGATIVE}/\texttt{NONE}), \textbf{causal motivation} (natural language mechanism explanation), and \textbf{scientific citations} (peer-reviewed references).

\subsection{Design Framework}

%------------------------------------------------------------------------------
\subsubsection{Per-RQ Experimental Design (RQ1a, RQ1b, RQ2, RQ3)}
\label{sec:per_rq_design}
%------------------------------------------------------------------------------

The design framework is instantiated in four main experiments (RQ1a, RQ1b, RQ2, RQ3). We summarize the \textbf{unit of analysis}, \textbf{treatments}, \textbf{datasets}, and \textbf{outputs} here to make the per-RQ design explicit (full specifications appear in Sections~\ref{sec:rq1a_experiments},~\ref{sec:rq1b_experiments},~\ref{sec:rq2_experiments}, and~\ref{sec:rq3_experiments}). The blocking structure and unit of inference for the main repeated-measures experiments are defined immediately below (Section~\ref{sec:block_design}).

\paragraph{RQ1a (Judge detection).}
\textbf{Goal:} measure whether LLM judges detect hallucinated edges.
\textbf{Design:} a \textbf{2$\times$2 factorial design} crossing \textbf{Ground Truth type} \(\in\{\text{GT Lit},\text{GT Synth}\}\) with \textbf{Judge type} \(\in\{\text{Correctness},\text{Citation}\}\), yielding four experimental cells. Within each cell we use a blocked repeated-measures structure with blocks = CLD$\times$run ($N=9$), and prompt variant as the within-block factor.
\textbf{Datasets:} \textbf{GT Lit} (hallucination = FP/FN w.r.t.\ literature ground truth) and \textbf{GT Synth} (hallucination = \texttt{corrupted=True} after synthetic corruption).
\textbf{Outputs:} per-edge judge scores and binary hallucination labels; aggregated block means for inference.

\paragraph{RQ1b (Corrector efficacy).}
\textbf{Goal:} test whether a corrector improves edge quality on judge-flagged edges.
\textbf{Design:} blocked repeated-measures with blocks = CLD$\times$run ($N=9$), within-block factor = corrector prompt.
\textbf{Datasets:} judge-flagged edges from RQ1a (both GT Lit and GT Synth conditions).
\textbf{Outputs:} pre/post correction edge tables and re-judged scores; block-level improvements \(\Delta\)Precision/\(\Delta\)Recall/\(\Delta\)F1 and \(\Delta\)judge score.

\paragraph{RQ2 (Context-insensitive detection via UQ).}
\textbf{Goal:} evaluate whether generator-side uncertainty metrics predict hallucinations without external context.
\textbf{Design:} blocked aggregation with blocks = CLD$\times$run ($N=9$); inference uses block means.
\textbf{Datasets:} deduplicated \textbf{GT Lit} runs (edges-only generation over fixed node sets); hallucination labels defined as FP/FN w.r.t.\ GT Lit.
\textbf{Outputs:} per-edge UQ metrics (perplexity, min probability, max window entropy; plus cosine similarity for citation runs), per-file and per-block AUCs, and (optionally) ensemble classifier performance under group-aware splits.

\paragraph{RQ3 (Deep Research literature validation).}
\textbf{Goal:} test whether the Deep Research system can distinguish valid from hallucinated causal claims by finding \textbf{direct causal evidence} in the scientific literature.
\textbf{Design:} \textbf{exploratory pilot study} (single-run, no replication) due to computational cost; analysis is descriptive with confirmatory tests limited to class-wise differences in detection rates (see Section~\ref{sec:rq3_experiments}).
\textbf{Datasets:} a stratified sample of edges from RQ1a GT Lit experiments, labeled by GT Lit validation class (TP/FP/FN).
\textbf{Outputs:} per-edge Deep Research verdicts (\texttt{direct\_causal\_found}, confidence, evidence list/URLs) and class-wise detection rates (TP/FP/FN) with associated uncertainty and discrimination tests.

\subsubsection{Design Rationale and Unit of Inference}
\label{sec:block_design}
\begin{itemize}[noitemsep]
    \item \textbf{GT Lit experiments:} CLD generation varies (seeds 10, 20, 30) $\rightarrow$ tests judge generalization across CLD instances
    \item \textbf{GT Synth experiments:} Corruption varies (seeds 1, 2, 3), base CLD fixed $\rightarrow$ isolates corruption detection ability
    \item \textbf{Seed separation:} Methodological independence between paradigms (10/20/30 vs 1/2/3)
\end{itemize}

\textbf{Confound Prevention:} The seed structure explicitly controls for potential confounds. In GT Synth experiments, fixing the base CLD while varying only the corruption seed ensures that performance differences reflect the judge's ability to detect different corruption patterns---not differences in underlying CLD structure. In GT Lit experiments, CLD structure variation is intentional: we deliberately test whether the judge generalizes across different valid CLD realizations. The seed separation (10/20/30 for generation vs. 1/2/3 for corruption) maintains methodological independence.

Experiments use a \textbf{blocked (repeated-measures) design} with 9 independent blocks: 3 CLDs $\times$ 3 runs (seeds 10, 20, 30 for generation; 1, 2, 3 for corruption). This structure:

\begin{itemize}[noitemsep]
    \item \textbf{Controls for CLD-level variance:} Performance is confounded by domain difficulty (Depressive vs.\ Obesity vs.\ Social Norms); blocking isolates treatment effects.
    \item \textbf{Controls for run-to-run variance:} Different seeds produce different CLD instances; blocking treats each (CLD, run) pair as a subject.
    \item \textbf{Enables within-subject analysis:} Prompt variants or methods are compared within the same block, increasing statistical power.
\end{itemize}

\textbf{Unit of inference:} The block mean (average across prompts within a block) is the unit of analysis for meta-level statistical tests. This yields $N=9$ independent observations for hypothesis testing.

%------------------------------------------------------------------------------
\subsubsection{Pipeline Components (Summary)}
%------------------------------------------------------------------------------

The experimental pipeline consists of four core components (see Section~\ref{sec:system_architecture} for full details):

\begin{itemize}[noitemsep]
    \item \textbf{Generator (GPT-4.1, T=0.7):} Generates CLDs by iteratively proposing nodes and edges with causal narratives. Captures UQ metrics (perplexity, min probability, max window entropy) during generation for RQ2.
    \item \textbf{Judge (GPT-4.1/GPT-5-mini, T=0.0):} Evaluates each edge via correctness-based reasoning or citation-based literature verification. Outputs scores: 0.0 (INCORRECT / NOT\_SUPPORTED), 0.5 (PARTIALLY\_CORRECT / PARTIALLY\_SUPPORTED), 1.0 (CORRECT / SUPPORTED).
    \item \textbf{Corrector (GPT-4.1, T=0.7):} Attempts to repair judge-flagged hallucinations by revising causal narratives or changing edge types.
    \item \textbf{Deep Research (GPT-5, T=0.0):} Multi-agent literature search pipeline that finds direct causal evidence for edge claims (RQ3 only).
\end{itemize}

\subsection{Metrics}

\subsubsection{Definitions and Output Metrics}
\label{sec:metrics_definitions}
%------------------------------------------------------------------------------

This section consolidates all metrics used across experiments.

\paragraph{Classification Metrics (Judge Evaluation; RQ1a).}
\begin{itemize}[noitemsep]
    \item \textbf{AUC-ROC:} Area under the ROC curve (judge score vs.\ hallucination label). Baseline: AUC = 0.5 (random classification).
    \item \textbf{Precision:} $\mathrm{Precision}=\frac{TP}{TP+FP}$
    \item \textbf{Recall:} $\mathrm{Recall}=\frac{TP}{TP+FN}$
    \item \textbf{F1:} $\mathrm{F1}=\frac{2\cdot TP}{2\cdot TP+FP+FN}$
    \item \textbf{Correlation ($r$):} Point-biserial correlation between judge score $s$ and binary hallucination label $y\in\{0,1\}$:
    \begin{equation}
        r_{pb}=\frac{\bar{s}_1-\bar{s}_0}{s_s}\sqrt{pq}
    \end{equation}
    where $\bar{s}_1$ and $\bar{s}_0$ are mean scores for the $y{=}1$ and $y{=}0$ groups, $s_s$ is the sample standard deviation of scores, and $p=\Pr(y{=}1)$, $q=\Pr(y{=}0)$.
    \item \textbf{Classification threshold:} Judge score $\leq 0.5$ predicts hallucination.
    \item \textbf{Confusion matrix terms:} $TP=\#\{y{=}1,\hat{y}{=}1\}$, $FP=\#\{y{=}0,\hat{y}{=}1\}$, $FN=\#\{y{=}1,\hat{y}{=}0\}$, $TN=\#\{y{=}0,\hat{y}{=}0\}$.
\end{itemize}

\paragraph{Judge Output Scores.}
\begin{itemize}[noitemsep]
    \item \textbf{Correctness Judge:} 0.0 (INCORRECT), 0.5 (PARTIALLY\_CORRECT), 1.0 (CORRECT)
    \item \textbf{Citation Judge:} 0.0 (NOT\_SUPPORTED), 0.5 (PARTIALLY\_SUPPORTED), 1.0 (SUPPORTED)
\end{itemize}

\paragraph{Correction Metrics (RQ1b).}
\begin{itemize}[noitemsep]
    \item \textbf{$\Delta$F1, $\Delta$Precision, $\Delta$Recall:} Change from pre- to post-correction w.r.t.\ ground truth
    \item \textbf{$\Delta$Judge Score:} $\text{mean}(\text{corrected edges}) - \text{mean}(\text{original edges})$
\end{itemize}

\paragraph{UQ Metrics (RQ2).} Context-insensitive metrics captured during generation (see Section~\ref{sec:uq_metrics_definition} for full definitions):
\begin{itemize}[noitemsep]
    \item \textbf{Perplexity:} Average token-level uncertainty (capped NLL)
    \item \textbf{Min Probability:} Confidence floor---minimum token probability
    \item \textbf{Max Window Entropy:} Highest-uncertainty region (5-token sliding window)
    \item \textbf{Cosine Similarity:} Semantic alignment between narrative and citations (citation experiments only)
\end{itemize}

\paragraph{Deep Research Metrics (RQ3).}
\begin{itemize}[noitemsep]
    \item \textbf{Detection Rate:} Fraction of edges with \texttt{direct\_causal\_found=True}
    \item \textbf{Pairwise DR Gaps (pp):} $\text{DR}_{A} - \text{DR}_{B}$ for $A,B\in\{\text{TP},\text{FP},\text{FN}\}$ (reported for TP--FP, TP--FN, FP--FN). As a practical heuristic, $>20$pp indicates meaningful discrimination.
    \item \textbf{Confidence Score:} Deep Research self-assessed confidence (1--10; reported as mean by class and CLD).
    \item \textbf{Uncertainty for proportions:} Wilson score 95\% confidence intervals for detection rates (see Appendix~\ref{app:statistical_procedures_reference}).
    \item \textbf{Discrimination tests:} Fisher's exact test for differences in detection rates (with Bonferroni-adjusted p-values for the TP--FP / TP--FN / FP--FN family; see Appendix~\ref{app:statistical_procedures_reference}).
    \item \textbf{Effect sizes (RQ3):} Cohen's $h$ for detection-rate differences; odds ratio (OR) with 95\% CI from the $2\times2$ contingency table.
\end{itemize}

\subsection{Statistical Analysis Plan}

\subsubsection{Non-Parametric Testing Framework (Main Results)}
\label{sec:nonparam_framework}
%------------------------------------------------------------------------------

For \textbf{prompt sensitivity} (RQ1a, RQ1b), we use non-parametric repeated-measures tests because the number of independent replicates is small ($n=9$ blocks) and distributional assumptions are difficult to verify:
\begin{itemize}[noitemsep]
    \item \textbf{Friedman test} (see Appendix~\ref{app:statistical_procedures_reference}): Non-parametric equivalent of repeated-measures ANOVA; ranks observations within each block and tests whether rank sums differ across treatments.
    \item \textbf{Post-hoc Wilcoxon signed-rank tests} (see Appendix~\ref{app:statistical_procedures_reference}): Pairwise comparisons between specific prompts within matched blocks.
    \item \textbf{Effect size:} Kendall's $W$ ($<$0.1 negligible, 0.1--0.3 small, 0.3--0.5 medium, $\geq$0.5 large).
\end{itemize}

This framework is robust to small sample sizes, non-normality, and outliers. The trade-off is that it primarily answers \textit{whether prompts differ} (in a rank-based sense), but it does not yield the same kind of variance decomposition and sensitivity measures as parametric repeated-measures models.

\textbf{Sensitivity Analysis (Appendix~\ref{app:sensitivity_analysis}; Methods~\S\ref{sec:rq1a_sensitivity}).} For sensitivity-style interpretation (e.g., ``how much variability is explained by prompts''), we also report \textbf{Repeated-Measures ANOVA} (RM-ANOVA) with variance decomposition (e.g., $\eta^2_p$). The trade-off is the opposite of the non-parametric approach: RM-ANOVA is more interpretable for sensitivity, but it relies on stronger distributional assumptions that are hard to validate convincingly at $n=9$. We therefore treat RM-ANOVA as a \textit{secondary} sensitivity summary (reporting $F$, df, $p$, and $\eta^2_p$), and keep the non-parametric results as the primary inferential evidence for prompt differences.

\paragraph{RQ2 hypothesis tests (single-metric UQ detection).}
For each UQ metric, we compute a \textbf{block-level} AUC-ROC (blocks = CLD$\times$run, $n=9$) and test whether discrimination exceeds chance:
\begin{itemize}[noitemsep]
    \item \textbf{Primary test:} one-sample $t$-test on block-level AUCs vs.\ 0.5 (Appendix~\ref{app:statistical_procedures_reference}). $H_0:\mu_{\text{AUC}}=0.5$, $H_1:\mu_{\text{AUC}}\neq 0.5$.
    \item \textbf{Assumption check:} Shapiro--Wilk test on block-level AUCs (Appendix~\ref{app:statistical_procedures_reference}); when approximate normality is questionable, we report non-parametric robustness checks (e.g., rank-based separation diagnostics; Appendix~\ref{app:statistical_procedures_reference}).
    \item \textbf{Correlation aggregation:} Pearson $r$ is computed per experimental file and aggregated using Fisher $z$-transformation across files (Appendix~\ref{app:statistical_procedures_reference}).
\end{itemize}

\paragraph{RQ3 hypothesis tests (Deep Research discrimination).}
RQ3 compares \textbf{detection rates} (Found vs.\ Not Found for \texttt{direct\_causal\_found}) between edge classes:
\begin{itemize}[noitemsep]
    \item \textbf{Primary test:} Fisher's exact test on $2\times2$ contingency tables for TP--FP, TP--FN, and FP--FN (Appendix~\ref{app:statistical_procedures_reference}); p-values are Bonferroni-adjusted within this family.
    \item \textbf{Uncertainty:} Wilson score 95\% confidence intervals for detection-rate proportions.
    \item \textbf{Effect sizes:} Cohen's $h$ for proportion differences, and odds ratio (OR) with 95\% CI from the contingency table.
\end{itemize}

%------------------------------------------------------------------------------
\subsubsection{Multiple Comparison Corrections}
\label{sec:multiple_comparisons}
%------------------------------------------------------------------------------

Bonferroni corrections control family-wise error rate, grouped by research question (see Appendix~\ref{app:statistical_procedures_reference}):
\begin{itemize}[noitemsep]
    \item \textbf{RQ1a:} Post-hoc prompt comparisons within each judge$\times$GT setting: \textbf{Correctness Judge} uses $k=3$ prompts $\rightarrow$ 3 pairwise comparisons, $\alpha_{\text{adj}} = 0.0167$; \textbf{Citation Judge} uses $k=4$ prompts (including \textbf{GT Lit} and \textbf{GT Synth}) $\rightarrow$ 6 comparisons, $\alpha_{\text{adj}} = 0.0083$
    \item \textbf{RQ1b:} 2 omnibus Friedman tests $\rightarrow$ $\alpha_{\text{adj}} = 0.025$; post-hoc 3 pairs $\rightarrow$ $\alpha_{\text{adj}} = 0.0167$ (see Appendix~\ref{app:statistical_procedures_reference})
    \item \textbf{RQ2:} 4 single-metric tests $\rightarrow$ $\alpha_{\text{adj}} = 0.0125$
    \item \textbf{RQ3:} 3 Fisher's exact tests $\rightarrow$ $\alpha_{\text{adj}} = 0.017$ (see Appendix~\ref{app:statistical_procedures_reference})
\end{itemize}

\textbf{Scope of correction families.} Unless stated otherwise, we apply Bonferroni corrections \emph{within each research question} (RQ) and within the corresponding family of statistical tests listed above. For RQ1a and RQ1b prompt-sensitivity analyses, corrections apply to post-hoc prompt comparisons within each experiment/metric (e.g., a given judge$\times$GT setting and metric such as F1 or AUC). We do not apply a single global correction across all RQs because each RQ tests a distinct hypothesis and is reported as a separate confirmatory family.

\subsubsection{Uncertainty Reporting Rule}
\label{sec:uncertainty_rule}
%------------------------------------------------------------------------------

For repeated measurements (across CLDs, runs/seeds, or CV folds), we report \textbf{mean [min, max]} as an assumption-free summary. 95\% confidence intervals are reserved for instance-level evaluations with large sample sizes ($N \geq 30$) or block-level meta-inference ($N=9$ blocks, t-distribution with $df=8$).

\textbf{Interpretation:} mean [min, max] is descriptive; 95\% CIs are inferential under the stated model. CV fold scores are not independent draws (folds share training data), so fold-based intervals should not be interpreted as strict confidence intervals.

\textbf{Statistical Power.} Post-hoc power analysis ($\alpha = 0.05$) is computed per-RQ based on observed effect sizes and sample sizes. All effect sizes, p-values, and power interpretations are summarized in Table~\ref{tab:effect_size_summary} (Results).

\subsubsection{Structure of Experimental Details}

The remainder of Methods expands each row of Table~\ref{tab:master} into a reproducible specification. To make experiments easy to scan and compare, each experiment section follows a consistent structure:
\begin{itemize}[noitemsep]
    \item \textbf{RQ \& Goal / Hypotheses:} What the experiment is testing and the expected direction of effects.
    \item \textbf{Source Data:} Which datasets/edge tables are used and how ground truth labels are defined (GT Lit vs.\ GT Synth, TP/FP/FN).

\end{itemize}

\subsection{Prompt sensitivity analysis}
\label{sec:rq1a_sensitivity}
%------------------------------------------------------------------------------

\paragraph{RQ \& Goal.}
Quantify prompt engineering impact on judge performance using variance-based sensitivity analysis inspired by Sobol indices~\cite{sobol1993sensitivity}.

\paragraph{Source Data.}
Prompt-level and block-level results from the four RQ1a judge experiments (summarized in Table~\ref{tab:master}).
\textbf{Appendix pointer:} Sensitivity output directory in Appendix~\ref{sec:data_availability} (Table~\ref{tab:experiment_datasets}).

\paragraph{Simulation Parameters.}
\begin{itemize}[noitemsep]
    \item \textbf{Design:} Blocked with CLD$\times$run as subjects, prompt as within-subject factor
    \item \textbf{Prompt distance:} MPNet~\cite{song2020mpnet} embeddings (768-dim); cosine distance from baseline: $d(p_i) = 1 - \cos(\mathbf{e}_{\text{baseline}}, \mathbf{e}_i)$
    \item \textbf{Scope:} 4 experiments $\times$ 3--4 prompt variants
\end{itemize}

\paragraph{Simulation Procedure.}
Repeated-measures ANOVA with CLD$\times$run as subjects and prompt as within-subject factor.
\textbf{Appendix pointer:} Full RM-ANOVA tables and diagnostics in Appendix~\ref{app:sensitivity_analysis}.

\paragraph{Simulation Outputs.}
RM-ANOVA effect sizes ($\eta^2_p$), assumption diagnostics, and sensitivity figures for each judge$\times$GT setting.
\textbf{Appendix pointer:} Output artifacts in Appendix~\ref{sec:output_artifacts} (Table~\ref{tab:output_files}); sensitivity output directory in Appendix~\ref{sec:data_availability} (Table~\ref{tab:experiment_datasets}).

\paragraph{Metrics.}
Following Sobol's variance-based sensitivity framework, for a categorical factor $A\in\{1,\dots,K\}$ (here: prompt choice) the first-order index is:
\begin{equation}
S_A := \frac{\mathrm{Var}(\mathbb{E}[Y \mid A])}{\mathrm{Var}(Y)}.
\end{equation}
For categorical $A$, this reduces to $S_A=\eta^2$,
i.e., the population one-way ANOVA effect size (correlation ratio) for a categorical factor~\cite{saltelli2010variance}. In the main
experiments, we report $\eta^2_p$ (partial eta-squared) because our design is blocked by CLD$\times$run (repeated
measures), so the sensitivity measure is computed after controlling for these subject-level differences.
Partial eta-squared: $\eta^2_p = \frac{SS_{\text{prompt}}}{SS_{\text{prompt}} + SS_{\text{error}}}$. Measures proportion of within-subject variance in F1 explained by prompt choice. Interpretation (Cohen): $<$0.01 negligible, 0.01--0.06 small, 0.06--0.14 medium, $\geq$0.14 large.

\paragraph{Statistical Analysis.}

\subsubsection{Analysis Pipeline (6 Phases)}
\label{sec:rq2_analysis}
%------------------------------------------------------------------------------

\noindent\textbf{Procedure (6 phases):}\\
\textbf{Phases 1--3 (single-metric):} compute per-file AUC-ROC, aggregate to blocks ($N{=}9$), and test above-chance discrimination via one-sample $t$-test.\\
\textbf{Phase 4 (RFE):} Recursive Feature Elimination~\cite{pedregosa2011sklearn} with \texttt{GroupKFold(n\_splits=3)} over blocks; classifiers: LogReg, RF, GradBoost.\\
\textbf{Phase 5 (ensemble):} block-level train/test split (67\%/33\%) via \texttt{GroupShuffleSplit} and model selection on training blocks via \texttt{GroupKFold}; four classifiers including a neural network.\\
\textbf{Phase 6 (LOCO):} leave-one-CLD-out evaluation for cross-domain generalization. Full formal specification in Appendix~\ref{alg:classification}.\\
\textbf{Reproducible splitting protocol (Phases 4--6):}\\
Grouping key is \texttt{block\_id=cld\_run} (3 CLDs $\times$ 3 runs $\Rightarrow N{=}9$); rows are deterministically sorted by \((\texttt{block\_id}, \texttt{source\_file})\) prior to any group split; scaling uses \texttt{StandardScaler} fit on training blocks only.\\
Phase 4 holds out 3 blocks and trains on 6; evaluates \(k \in \{1,2,3,4\}\) and selects the \(k\) maximizing validation AUC per fold.\\
Phase 5 holds out 3 blocks for testing and uses the remaining 6 for training; CV on training uses 3 folds (2 blocks held out per fold).\\
Phase 6 holds out an entire CLD as test and trains on the other two CLDs (scaling fit on training CLDs only).\\
\textbf{Limitations:}\\
UQ metrics are not applicable for GT Synth (corruption is post-generation); cosine similarity is only defined for Citation Judge runs.\\
\textbf{Reproducibility:}\\
Data in \texttt{final\_runs/RQ2\_hallucination\_detection/} (inputs: deduplicated GT Lit files); scripts \texttt{rq2\_master\_report\_v2\_enhanced.py} and \texttt{rq2\_simple\_batch\_analyzer.py}; see Appendix~\ref{sec:code_availability} (Table~\ref{tab:analysis_scripts}).

\section{Threats to Validity}
\label{sec:threats_to_validity}
%==============================================================================

This section summarizes key threats to validity that graders commonly expect to see \emph{explicitly} addressed in the Methods. A longer, interpretive discussion (including qualitative failure mechanisms) appears in the Discussion chapter.

\subsection{Internal Validity (leakage, pseudo-replication, and dependence)}
Our data are highly structured: many edges come from the same generation scenario, and multiple prompt variants are evaluated within the same (CLD$\times$run) block. To reduce pseudo-replication and leakage, we adopt \textbf{block-aware} design and analysis choices throughout:
\begin{itemize}[noitemsep]
    \item \textbf{Blocked (repeated-measures) design:} We treat (CLD$\times$run) as the independent unit for prompt comparisons and meta-inference ($N=9$ blocks; Section~\ref{sec:block_design}).
    \item \textbf{Group-aware splitting:} For RQ2 ensemble models, all train/test and CV splits keep entire blocks together (GroupKFold / GroupShuffleSplit; Section~\ref{sec:rq2_analysis}), preventing leakage from correlated edges within the same scenario.
    \item \textbf{Edge-level results as descriptive:} When we plot pooled edge distributions, we treat them as diagnostics rather than edge-level inferential claims to avoid overstating significance under dependence.
\end{itemize}

\begin{itemize}[noitemsep]
    \item \textbf{Other validity considerations (construct, external, and conclusion validity):} Discussed in the Discussion chapter to avoid duplicating interpretive material; these points do not change the methodological procedures described above.
\end{itemize}
