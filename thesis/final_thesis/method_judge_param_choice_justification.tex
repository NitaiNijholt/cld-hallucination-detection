Prior work and common practice frequently run LLM-as-a-Judge at low temperature to improve reproducibility, so we use \textbf{temperature 0 with top\_p at default (1.0)}. We do not claim this is universally optimal across all evaluation setups; rather, it is a conservative choice that reduces sampling variance and makes repeated judge runs more comparable. Regarding top\_p, provider guidance typically recommends varying \emph{either} temperature \emph{or} top\_p (not both), so we leave top\_p at its default and vary temperature only when needed.

A caveat is that \textbf{temperature 0 does not guarantee perfect determinism}: backend nondeterminism (e.g., floating-point effects, hardware/runtime differences, parallelism, and routing in some architectures) can still lead to occasional output variability. In practice, this motivates repeated evaluation runs and reporting uncertainty (e.g., via bootstrap confidence intervals) when comparing models or prompts.
